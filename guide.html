動作環境

  • Windows（64bit）
  • Java のインストールは不要（アプリに同梱）
  • ディスクの空き容量 約 200MB（展開後）

動作確認済み: Windows 11 Home（64bit）

ダウンロードと起動

  1. ダウンロード から ZIP ファイルを入手します。
  2. ZIP を右クリックして「すべて展開」を選びます。
  3. 展開した Manemane フォルダの中の Manemane.exe をダブルクリックします。

Manemane フォルダの中身は、まとめて置いたまま使ってください。Manemane.exe だけを別の場所に移すと起動しません。デスクトップから起動したい場合は、ショートカットを作成してください。

初回起動時に「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を選んでください。署名のない個人開発のアプリのため表示されます。

初回セットアップ

初めて起動すると、次の2つを設定する画面が表示されます。

項目内容
通常の給料日毎月の給料日（例: 25日）。土日の場合は直前の金曜日として扱います。
最初の期間の開始日直近の給料日が入っています。この日より前の明細は登録できません。

最初の期間の「前期繰越」は 0 円で始まります。これまでの家計簿から引き継ぐ金額がある場合は、メイン画面の「前期繰越」カードの「編集」で入力してください（不足している場合はマイナス）。

メイン画面の見方

表示内容
期間給料日から次の給料日の前日まで。最新の期間の終了日は「次の給料日（予定）の前日」で、（予定）と表示されます。
収入期間内の収入の合計
前期繰越前の期間の残額（不足ならマイナス）
利用可能金額収入 ＋ 前期繰越
固定費・変動費・投資・積立期間内のそれぞれの合計
残額利用可能金額 − 固定費 − 変動費 − 投資・積立。マイナスのときは赤く表示されます。

右側には、今期と前期の支出、カテゴリ別の支出のグラフが表示されます。明細の一覧は「全て／収入／固定費／変動費／投資・積立」で絞り込めます。

明細の登録・編集

「+ 支出」または「+ 収入」を押して入力し、「保存」を押します。

  • 区分 … 支出は「固定費／変動費／投資・積立」、収入は「固定／変動」。
  • 項目 … 入力すると過去の項目名が候補に出ます。候補を選ぶと、前回のカテゴリと支払方法が入ります。
  • 保存して続けて入力 … 日付と区分を残したまま、次の明細を入力できます。

編集・削除・複製

  • 編集: 行をダブルクリック、または行を選んで Enter
  • 削除: 行を選んで Delete（確認が表示されます）
  • 複製: 行を右クリック →「複製して追加」

電子マネー（PayPay・交通系 IC など）は「チャージした金額」を支出として登録し、カテゴリを「電子マネーチャージ」にします。チャージ残高から払った買い物は、二重になるため登録しません。

新しい期間と繰越

給料が入ったら

「新しい期間を開始」を押します。給料日には次の給料日の予定日が入っています（実際の給料日と違えば変更します）。確定する期間と繰り越す金額を確認して「開始」を押してください。

「有効な固定費を新しい期間に反映する」にチェックがあると、登録済みの固定費が新しい期間に自動で登録されます。

繰越

期間の残額は、プラスもマイナスも次の期間の「前期繰越」へ自動で引き継がれます。「前期繰越」カードの「編集」から手入力で上書きでき、「自動計算」に戻すこともできます。

固定費

メニュー「管理」→「固定費…」で、家賃・サブスク・積立などを登録します。項目名・区分（固定費／投資・積立）・金額・支払日（毎月◯日）・カテゴリ・支払方法を設定できます。

メイン画面の「固定費を反映」で、表示中の期間に明細として登録します。支払日は期間内の日付に置き換えられ（例: 期間 9/25〜10/22 で 27日払い → 9/27）、同じ期間に二重に登録されることはありません。

集計（グラフ・年間）

メイン画面の右側で、今期・前期の支出と前期との差、カテゴリ別の支出（金額と割合）を確認できます。

年間の収支

メニュー「集計」→「年間の収支…」で、1月1日〜12月31日の収入合計・支出合計・収支と、月別の表を確認できます。給料日の期間ではなく、明細の日付で集計します（繰越は含みません）。

カテゴリ・支払方法

メニュー「管理」→「カテゴリ・支払方法…」で、追加・名前の変更・並べ替え・削除ができます。明細や固定費で使われているものは、削除の代わりに「無効」になります（過去の明細には残り、新しい入力の選択肢から消えます）。「無効も表示」にチェックすると、有効に戻せます。

バックアップと PC の移行

  • バックアップ … メニュー「ファイル」→「バックアップ…」で保存先を選びます。USB メモリやクラウドのフォルダに定期的に保存しておくと安心です。
  • 復元 … メニュー「ファイル」→「バックアップから復元…」でファイルを選びます。中身（明細の件数など）を確認してから置き換えます。置き換える前のデータは自動で保存されます。

パソコンを買い替えるとき

  1. 古いパソコンでバックアップを作ります。
  2. 新しいパソコンでアプリを起動します（初回セットアップの内容は何でも構いません）。
  3. 「バックアップから復元…」で 1. のファイルを選びます。

Excel の書き出し・取り込み

書き出し … メニュー「ファイル」→「Excel に書き出す…」。「表示中の期間」か「すべての期間」を選ぶと、「明細」「集計」「カテゴリ別」の3つのシートができます。

取り込み … メニュー「ファイル」→「Excel から取り込む…」。取り込む前に、取り込める行・取り込めない行（理由付き）・既存の明細と重複の可能性がある行を確認できます。

取り込むファイルの形式

読み込むのは「明細」シートだけです（なければ最初のシート）。1行目が見出し、2行目からが明細です。列の順番は自由です。

列名必須書き方
日付○2026/10/04 など（Excel の日付でも可）
種類○収入／支出／投資・積立
項目○例: スーパー
金額○整数の円（1,200 や 1200円 も可）
カテゴリ○アプリに登録済みの名前と同じにする
固定/変動固定／変動（空欄なら変動）
支払方法登録済みの名前（収入の行は空欄）
メモ自由

いちばん確実なのは、一度書き出したファイルの「明細」シートをひな形にして、行を書き足す方法です。

キーボードの操作

キー操作
F1使い方を表示
Ctrl + N支出を追加
Ctrl + I収入を追加
Alt + ← / →前の期間／次の期間
Enter（一覧で）選んだ明細を編集
Delete（一覧で）選んだ明細を削除
Esc入力画面を閉じる

データの保存場所・削除

データは %APPDATA%\Manemane\kakeibo.db に保存されます（エクスプローラーのアドレス欄に %APPDATA%\Manemane と入力すると開けます）。インターネットへの送信は行いません。

アプリを削除するときは Manemane フォルダを削除してください。データも消す場合は、上の保存場所のフォルダも削除します。

困ったとき

症状対処
起動しないManemane.exe と同じ場所に app・runtime フォルダがあるか確認してください。
アイコンが古いままエクスプローラーで F5 を押すか、フォルダを開き直してください。
「新しいバージョンのアプリで作成されています」新しいバージョンで保存されたデータです。アプリを更新してください。
明細が登録できない（日付のエラー）最初の期間の開始日より前の日付は登録できません。
Excel が取り込めないExcel でそのファイルを開いている場合は閉じてください。確認画面の「理由」に原因が表示されます。
